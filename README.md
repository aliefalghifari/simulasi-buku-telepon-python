# Simulasi Buku Telepon Python

Aplikasi buku telepon sederhana berbasis terminal menggunakan Python dan penyimpanan data JSON.

Project ini dibuat untuk mempelajari:
- Object Oriented Programming (OOP)
- Manajemen file JSON
- Validasi input
- Struktur project Python dasar
- Pemisahan logic program dan database

---

## Features

- Menambahkan kontak baru
- Menampilkan daftar kontak
- Memilih kontak untuk dihubungi
- Penyimpanan data menggunakan JSON
- Validasi input sederhana

---

## Technologies Used

- Python 3
- JSON File Storage

---

## Project Structure

```txt
.
├── main.py
├── database.py
├── database.json
└── README.md
```

### File Description

| File | Description |
|---|---|
| `main.py` | Logic utama aplikasi terminal |
| `database.py` | Class untuk mengelola database JSON |
| `database.json` | Penyimpanan data kontak |
| `README.md` | Dokumentasi project |

---

## How to Run

### 1. Clone Repository

```bash
git clone https://github.com/aliefalghifari/simulasi-buku-telepon-python.git
```

### 2. Masuk ke Folder Project

```bash
cd simulasi-buku-telepon-python
```

### 3. Jalankan Program

```bash
python main.py
```
